# Universal Transform Gizmo (for Blender 5.3)

Vastly improved transform gizmo (widget) for Blender 5.3+

Design improvments inspired by [SDF Modeler](https://sascha-rode.itch.io/sdf-modeler), [MagicaCSG](https://www.patreon.com/c/magicavoxel), Unreal Engine!

## 🎁 Features
* One gizmo to rule them all. No need to switch between gizmo modes.
* Gizmo handles always face the camera.
* Both single and double sided location arrows supported.
* Huge number of tweak options to fit your personal preference exactly.

## Install

[Download](https://github.com/gnat/blender_universal_transform_gizmo/archive/refs/heads/main.zip) and extract `blender_universal_transform_gizmo` into your Blender addons folder.

* Linux: `~/.config/blender/5.3/scripts/addons/`
* Windows: `C:\Users\USER\AppData\Roaming\Blender Foundation\Blender\5.3\scripts\addons`

Enable it: Start Blender ➡️ Edit ➡️ Preferences ... ➡️ Add-ons ➡️ Extra Tools for Viewport Header Menu ✅
